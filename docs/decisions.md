# Initial implementation decisions

- Go implements the CLI, synchronization engine, and target interface.
- TypeScript implements the Docusaurus plugin and component handlers.
- The initial target supports Confluence Cloud only.
- Confluence authentication uses an account email and API token from
  environment variables.
- Terraform and external target processes are deferred.
- The public Go target interface permits future target integrations.
- Every Docusaurus documentation route and custom page is in scope.
- Authored and generated documents are in scope.
- Sidebar category index documents become category pages.
- The Docusaurus source is authoritative.
- Managed pages have `autogenerated` and `docusynx-managed` labels.
- Managed pages contain a visible link to their source and source commit.
- Synchronization updates existing pages and deletes removed managed pages.
- Deletion is allowed only when ownership metadata and namespace match.
- Named targets and publications are part of the configuration contract.
- Change validation builds and tests offline.
- Fake-server tests run in normal automation.
- Live acceptance tests require an explicit test space and credentials.
